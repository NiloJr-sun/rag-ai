## Running it

Prerequisites: [Ollama](https://ollama.com), Python 3.12, and a Postgres with
pgvector (a Supabase project, or `pgvector/pgvector:pg16` in Docker).

```bash
# models
ollama pull nomic-embed-text      # embeddings, 768 dimensions
ollama pull qwen2                 # chat

# environment
uv venv --python 3.12 .venv
source .venv/bin/activate
uv pip install -e "backend[dev]"

# database (once)
export DATABASE_URL='postgresql://...'
psql "$DATABASE_URL" -f backend/migrations/0001_init.sql

# ingest, then ask
python scripts/ingest.py data/samples
python scripts/ask.py "How does cosine similarity work?"
python scripts/ask.py                       # interactive, Ctrl-D to quit
```

`ingest.py` takes a file or a directory and accepts `--reset`, `--max-size`
and `--skip-failures`. `ask.py` accepts `--top-k` and `--show-chunks`.

### Exploring the pieces

Each primitive has a demo script and a write-up in [docs/rag/](docs/rag/):

| script | shows |
|---|---|
| `scripts/embed_demo.py` | text → 768 floats |
| `scripts/similarity_demo.py` | ranking sentences by meaning |
| `scripts/chunking_demo.py` | chunking strategies compared by retrieval |
| `scripts/search_demo.py` | retrieval from the database at several k |
| `scripts/verify_supabase.py` | schema check: pgvector agrees with Python |

### Tests

```bash
pytest backend/tests                        # unit tests, no services needed
DATABASE_URL=... pytest backend/tests       # adds the storage integration tests
```
